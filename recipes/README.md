# recipes/

这里放**你自己的配方**，只留在本机，不进 git（见 `.gitignore`）。

- `current.json`：AI 按 SKILL.md 生成、准备要冲的那一份。每换一支豆子会被覆盖。
- 想留住某个调好的配方，另存成 `recipes/<名字>.json` 即可，同样不会被提交，升级技能（`git pull`）也不会冲掉。

刚装好时这里没有 `current.json`。格式参照 [`examples/ethiopia-duwancho.recipe.json`](../examples/ethiopia-duwancho.recipe.json)。
